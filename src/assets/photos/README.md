# Photos

Drop real photos here, named after their slot. The build picks them up and serves AVIF/WebP in several widths. No code change needed.

| File name (any of .jpg .jpeg .png .webp .avif) | What it should show |
| --- | --- |
| `svc-beton` | Fabrika betona u Padini |
| `svc-agregati` | Frakcije šljunka izbliza, pored lenjira |
| `svc-materijal` | Stovarište i kamion sa kranom |
| `svc-gradnja` | Završen objekat ili hala |
| `svc-poljoprivreda` | Silos u žetvi |
| `svc-ogrev` | Složena drva i ugalj |
| `frakcija-f1` | Pesak 0–4 mm, iz blizine |
| `frakcija-f2` | Šljunak 4–8 mm, iz blizine |
| `frakcija-f3` | Šljunak 8–16 mm, iz blizine |
| `frakcija-f4` | Šljunak 16–32 mm, iz blizine |
| `frakcija-ib` | Iberlauf, iz blizine |
| `frakcija-mix` | Prirodna mešavina, iz blizine |
| `frakcija-dk` | Drobljeni kamen, iz blizine |
| `galerija-1` | Auto-beton pumpa 42 m |
| `galerija-2` | Industrijski pod u hali |
| `galerija-3` | Separacija Jarkovac, iz drona |
| `galerija-4` | Ispitivanje kocke u laboratoriji |
| `galerija-5` | Mikseri u nizu |
| `galerija-6` | Stovarište i kamion sa kranom |

| `o-nama-tim` | Osnivač i tim ispred fabrike betona |

Use landscape photos at least 2000 px wide (the team photo is portrait, 4:5). Alt text comes from the slot caption; pass `alt` to `<Photo>` to override it.
